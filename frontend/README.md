# Frontend - Product Review Sentiment Classification

React.js frontend for Real-Time Product Review Sentiment Classification System.

## Setup

1. Install dependencies:
```bash
cd frontend
npm install
```

2. Start development server:
```bash
npm start
```

The app will open at `http://localhost:3000`

## Features

- ✅ Real-time authentication (Login/Register)
- ✅ Live dashboard with system status
- ✅ Review input with word count
- ✅ Real-time sentiment results
- ✅ Explainable AI with word highlighting
- ✅ AI chatbot interface
- ✅ Auto-training status monitoring
- ✅ System analytics dashboard

## Backend Integration

The frontend connects to the Flask backend at `http://localhost:5000` (configured in `src/utils/api.js`).

Make sure the backend is running before starting the frontend!
